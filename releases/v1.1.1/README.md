# baidu-mcp-transfer 1.1.1

发布日期：2026-11-02

[下载安装包](baidu-mcp-transfer-1.1.1.zip)

本版本包含通用任务面板与终端兼容修复。上传、下载和提供兼容状态文件的同步任务可自动发现；速度统计排除跳过已有文件的字节；未识别的终端类型可回退到 xterm。外部 MCP 未提供进度时仅显示在线及未接入进度，不推断传输速度。

安装包内附安装说明、任务元数据接入文档和回归测试。已通过 Linux 全新安装、45 项测试以及真实 stdio MCP 握手与离线模拟分片测试。验证未进行真实网盘传输。

本次发布仅新增此版本目录，仓库现有源码及其他文件保留。安装包不含凭据、用户文件或当前服务器的任务记录。安装器遇到已有目录或启动器会停止，不自动覆盖。

shasum -a 256 -c SHA256SUMS
