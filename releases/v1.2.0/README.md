# baidu-mcp-transfer 1.2.0

发布日期：2026-11-02

[下载安装包](baidu-mcp-transfer-1.2.0.zip)

此版本包含之前的通用任务面板与终端兼容修复，并新增服务器文件授权和自动续期。

- 使用 `baidu-tui --authorize --check-dir /实际网盘目录` 隐藏输入 AppKey、SecretKey 和授权码；验证后保存访问令牌、刷新令牌及有效期。
- 在到期前一小时，传输请求按需刷新，无需手动操作；空闲时不执行后台刷新。
- 上传元数据、预创建、分片、完成请求及下载元数据请求重新读取有效令牌；多个进程共用刷新锁。
- 新访问令牌和刷新令牌一起原子保存，保留其他配置并备份原文件；目录与文件权限为700/600。
- 刷新失败或结果不确定时停止，不反复尝试同一刷新凭据；授权被撤销或刷新凭据失效时仍须重新授权。

新安装请下载本目录 ZIP 并按包内 INSTALL.md 操作，包内附自动续期及任务元数据文档。安装器仍拒绝覆盖已有安装，可安装到独立目录后切换入口。

已通过 Linux 全新安装、54 项离线回归测试、真实 stdio MCP 握手和模拟分片测试。续期功能先前已在指定服务器验证一次真实刷新及网盘访问。此发布验证没有上传用户文件，不包含凭据、服务器连接信息或任务记录。

本次仅新增该版本目录，保留旧版本以及仓库根目录的既有源码和其他文件。新版安装请使用此 ZIP。

校验：

```bash
shasum -a 256 -c SHA256SUMS
```
